# service-engine

The reactive personalized delivery and process skeleton every BotResources
service runs on: sessions, cohorts, impacts, projection, diff, multi-pod
fan-out, streaming sources, boot, relays, cron, and mirror supervision.

**Status: scaffold; implementation ships with 0.1.0.** This crate is empty at
`v0.0.0` — it carries no code and no dependency.

```toml
[dependencies]
service-engine = { git = "https://github.com/BotResources/br-service-engine", package = "service-engine", tag = "v0.0.0", version = "0.0.0" }
```
